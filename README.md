# coffee_Sales_dashboard
An interactive Excel dashboard designed to analyze coffee sales performance, customer trends, product demand, and revenue insights using dynamic charts, KPIs, and slicers. The dashboard provides location-wise, hourly, and category-wise sales analysis to support better business decision-making.

☕ Coffee Sales Analysis Dashboard

An interactive Coffee Sales Analysis Dashboard built in Microsoft Excel to analyze coffee shop sales performance, customer purchasing patterns, and product trends through dynamic visualizations and KPI tracking.

🚀 Features
Interactive and visually appealing dashboard
KPI Cards for:
Total Quantity Sold
Total Transactions
Total Revenue
Hourly Sales Trend Analysis
Top 10 Products by Quantity
Location-wise Sales Distribution
Product Category Analysis
Product Type Distribution
Size-wise Sales Analysis
Interactive Slicers for:
Day Name
Month Name
